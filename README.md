**Name:** Madison Honeycutt

**Language:** C#

## About this Lab

This lab demonstrates event-driven programming in C# using Avalonia to create a graphical application for a coffee shop. The application manages customer orders, updates waiting and pickup lists, and tracks rewards for completed drinks. It uses event handlers to respond to button clicks, update the interface, and notify customers when they earn a free drink.

## How to run

To open the Corner Cup window, use:

```
dotnet run
```

To run the automated lab check instead, use:

```
dotnet run -- check
```

The check runs all four parts and prints their results to the console without opening the window.
